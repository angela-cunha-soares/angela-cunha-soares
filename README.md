## 🚀 Projects

### 🌱 EVAonline
Title: An open-source web platform for global reference evapotranspiration estimation via multi-source data fusion.

- Data fusion from different climate sources  
- Adaptive Kalman filtering for missing data  
- Agroclimatic indicators for water management  
- Validated with BR-DWGD dataset (MATOPIBA region)  

🔗 https://evaonline.app.br/

---

### 🌾 Irrigation & Climatological Water Balance Model
Title: Forecasting Water Balance and Daily Irrigation Requirements Using Climate Data: A Case Study in Balsas, Brazil.

- Based on 60 years of climate normals  
- Probabilistic modeling approach  
- Estimation of irrigation depth (lâmina de irrigação)  
- Support for agricultural water management
